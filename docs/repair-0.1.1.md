# v0.1.1 修缮记录

日期：2026-10-22。本次仅修改独立的 `photo-audit` 项目，没有操作个人图库或云端账号，没有安装新依赖或公开发布。

## 实际改动

1. 刷新页面时，恢复本机服务中最近的核对记录；若任务仍在运行，继续轮询其进度，不重复读取图库。
2. 新路径错误时保留上一份核对结果和下载入口。报告区域显示实际来源与目标，避免与尚未成功提交的新输入混淆。
3. 修复“跳到核对区域”链接改写 URL 片段后，刷新会丢失会话的问题。仅在当前标签页的 sessionStorage 保留随机会话令牌，不把路径或报告存入浏览器历史存储。
4. macOS 增加选择文件夹和 ZIP 的按钮，仅在点击时调用系统选择窗口。取消不清空原路径，选中后也不自动扫描；超时或不可用时提示粘贴路径。
5. 启动脚本检查 Python 最低版本，支持传入 `--no-browser` 等启动参数。端口范围错误、端口占用等启动问题给出明确提示；绑定失败时清理创建的临时资源。
6. 修复异常非 ASCII 会话令牌可能导致请求处理抛错的问题，统一拒绝为 403。
7. 界面和报告统一标记版本 0.1.1。继续保持原有只读核对语义。

## 验证范围

含 Pillow 的 Python 3.12.14 环境：46 项自动测试全部通过。不含 Pillow 的 Python 3.14.8 环境：44 项通过，2 项图片解码测试明确跳过。Ruff 检查通过。

通过实际 `.command` 脚本加 `--no-browser` 启动本机服务，再用现有 Chrome 的独立无界面会话验证了：演示计数、四类列表、报告下载、桌面和窄屏布局、键盘切换、错误输入保留旧结果、刷新恢复而不重扫、无障碍锚点跳转后的恢复，以及 137 条结果的三页分页。查看了桌面和窄屏截图，未见主要内容遮挡或页面横向溢出。桌面浏览器测试未观察到外部地址请求。

系统选择窗口的两段 AppleScript 均经本机 `osacompile` 实际编译通过。路径、取消、超时和不支持平台的处理经模拟进程结果测试；浏览器按钮通过模拟 API 响应验证赋值和取消保留。**本轮没有实际打开并点选原生选择对话框，不能将模拟测试记为原生窗口已完成实测。**

证据目录为 `artifacts/repair-2026-10-22/`，含桌面/窄屏截图及小型演示的 HTML、JSON 下载报告。上一轮 6090 条目和 64 MiB 检查结果仍保留在原测试目录，没有重复运行，也不作为本次新增验证计数。

## 使用与边界

关闭旧启动窗口后重新运行启动脚本，才会加载新的后端。服务关闭后仍不会保存内存中的核对结果；要长期保留，应另存 HTML 或 JSON 报告。

本次没有增加断点续扫、云端对接、相册/拍摄日期核验或视频全程解码。真实图库、真实云端导出和原生对话框实际点选仍需后续验证。
